### 2. Member 模式流程

**代码位置**: `tasks/Orochi/script_task.py:219-264`

**核心流程**:
```python
def run_member(self):
    logger.info('Start run member')
    self.ui_get_current_page()
    
    # 主循环：等待邀请 → 接受 → 进入房间 → 等待队长开启战斗
    while 1:
        self.screenshot()
        
        # 次数/时间限制检查
        if self.current_count >= self.limit_count: break
        if datetime.now() - self.start_time >= self.limit_time: break
        
        # 检测并接受邀请
        if self.check_then_accept(): continue
        
        # 进入房间后等待战斗
        if self.is_in_room():
            if self.wait_battle(wait_time=...):
                self.run_general_battle(...)
            else:
                break
        
        # 处理秒开情况
        elif self.check_take_over_battle(...): continue
    
    # 退出清理
    while 1:
        if self.exit_room(): pass
        if self.exit_battle(): pass
```

**关键方法**:
- `check_then_accept()`: 检测邀请弹窗并自动接受（继承自 `GeneralInvite`）
- `is_in_room()`: 判断是否在组队房间
- `wait_battle()`: 等待队长开启战斗
- `run_general_battle()`: 执行战斗流程

## 调用方式决策

### 推荐方式：设置 `user_status=member` 后调用 `run()`

**理由**:

1. **复用完整流程**: 包括 buff 管理、次数/时间限制、异常处理
2. **最小化修改**: 不需要手动管理 buff 开关
3. **上游兼容**: 不依赖 `run_member()` 方法签名（内部实现细节）

**实现模式**:

```python
def _execute_orochi_member(self, invite: InviteInfo) -> bool:
    """执行御魂 member 模式"""
    from tasks.Orochi.script_task import ScriptTask as OrochiTask
    
    # 保存原始配置
    original_user_status = self.config.orochi.orochi_config.user_status
    original_buff_enable = self.config.orochi.orochi_config.soul_buff_enable
    
    try:
        # 临时修改为 member 模式
        self.config.orochi.orochi_config.user_status = UserStatus.MEMBER
        
        # 应用被动响应的 buff 配置
        passive_buff_enable = self.config.passive_cooperation_response.passive_config.orochi.buff_enable
        self.config.orochi.orochi_config.soul_buff_enable = passive_buff_enable
        
        # 实例化并拦截 set_next_run
        runner = OrochiTask(self.config, self.device)
        
        def capture_next_run(task, finish=False, success=None, server=True, target=None):
            logger.info(f"PassiveCooperationResponse: Captured Orochi next_run (ignored)")
            return
        runner.set_next_run = capture_next_run
        
        # 调用 run() - 会自动分发到 run_member()
        runner.run()
        
        return True
    
    except TaskEnd:
        return True
    except RequestHumanTakeover:
        raise  # 向上传播
    except Exception as e:
        logger.exception(f"Failed to execute orochi member: {e}")
        return False
    finally:
        # 恢复原始配置
        self.config.orochi.orochi_config.user_status = original_user_status
        self.config.orochi.orochi_config.soul_buff_enable = original_buff_enable
```

## 风险与缓解

| 风险 | 缓解措施 |
|------|---------|
| 配置恢复失败（异常时） | 使用 `try-finally` 确保恢复 |
| `set_next_run` 污染 scheduler | 拦截方法，丢弃调用 |
| Buff 状态检测失败 | 复用现有 `open_buff()` / `soul()` 逻辑，已验证可靠 |
| Member 流程卡死 | 复用现有超时机制（`limit_time`, `wait_battle` timeout） |
